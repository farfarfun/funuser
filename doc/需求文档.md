# 用户管理系统需求文档

## 1. 系统概述

本系统基于 FastAPI 提供用户注册、登录、个人信息与密码管理 API。数据通过
SQLAlchemy 持久化，访问令牌使用 JWT，密码使用 bcrypt 哈希存储。

## 2. 用户数据

用户包含 `id`、`username`、`password`、`email`、`phone`、`status`、
`created_at` 和 `updated_at` 字段。用户名和邮箱唯一，密码字段只保存哈希值且不通过
API 返回。

## 3. API 接口

### 3.1 注册

- `POST /api/v1/register`
- JSON 请求字段：`username`、`password`、`email`，可选 `phone`
- 成功时返回用户公开字段；用户名或邮箱重复时返回 400

### 3.2 登录

- `POST /api/v1/login`
- JSON 请求字段：`username`、`password`（必须放在请求体，不能作为 URL 查询参数，避免凭据进入访问日志）
- 成功时返回 `access_token` 和 `token_type`

### 3.3 获取当前用户

- `GET /api/v1/users/me`
- 要求 Bearer JWT，成功时返回当前用户公开字段

### 3.4 更新当前用户

- `PUT /api/v1/users/me`
- 要求 Bearer JWT；JSON 请求可包含 `email`、`phone`
- 成功时返回更新后的用户公开字段

### 3.5 修改密码

- `POST /api/v1/users/me/change-password`
- 要求 Bearer JWT；JSON 请求字段为 `old_password`、`new_password`
- 旧密码错误时返回 400

服务运行时以 `/docs` 暴露由当前代码生成的 OpenAPI 交互文档。

## 4. 安全与配置

- 数据库地址和 JWT 密钥只能由环境变量或 `funsecret` 提供。
- 所有受保护接口均校验 Bearer JWT。
- 请求数据由 Pydantic 校验。

## 5. 技术栈

- Web 框架：FastAPI / Uvicorn
- 数据访问：SQLAlchemy
- 默认数据库：SQLite；可通过安全凭据配置 MySQL
- 认证：JWT
